# Foodwise Dashboard

Foodwise Dashboard is a React application designed to visualize and manage food inventory data. It provides various charts and tables to help users understand their food usage, waste, and restocking needs.

## Features

- Business Hours Chart
- Food Waste Visualization
- Inventory Data Table
- Key Performance Indicators (KPIs)
- Restock Prediction Chart
- Stock Usage Analysis
- Responsive Sidebar Navigation

## Installation

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd foodwise-dashboard
   ```

3. Install the dependencies:
   ```
   npm install
   ```

## Usage

To start the development server, run:
```
npm start
```

The application will be available at `http://localhost:3000`.
